# financial-analysis-api

REST API backend for the financial analysis dashboard. Built with Hono.js + Supabase.

## Setup
1. Copy `.env.local` and fill in values
2. `npm install`
3. `npm run dev`

## Testing
`npm test`

## Endpoints
- GET /health
- GET /api/projects
- GET /api/dashboard
- GET /api/member-dashboard
- GET /api/form-data
- GET /api/empresas
- GET /api/contratos
- POST /api/alocacao
- POST /api/clockify-sync
